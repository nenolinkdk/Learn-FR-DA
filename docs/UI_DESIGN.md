# UI Design

## Direction

Learn FR-DA should remain recognisably part of the Nenoling family while
receiving its own French-Danish visual identity.

## Palette

Conceptual palette: - pastel/off-white background - soft blue as primary
interface colour - muted red as accent - dark neutral text

Exact colour values should be chosen during implementation and checked
for accessibility.

## Principles

-   calm and readable
-   simple navigation
-   clear hierarchy
-   large enough touch targets
-   French UI text
-   Danish target text visually easy to identify
-   compact controls with usable touch targets
-   paired compact TTS buttons: Écouter FR / Écouter DA
-   round previous/next icon navigation next to the dialogue
-   visible progress without technical status clutter
-   discreet version line and home footer with external site link
-   no repeated decorative flags throughout the app

## Children

The Children / Enfants section may use more playful visual elements, but
should not become a separate visual product.

## Screens to inherit/rework from LP2

-   Welcome
-   Level/module selection
-   Lesson list
-   Dialogue/phrase screen
-   Grammar
-   Quiz
-   Progress/statistics
-   About/documentation
-   Settings if retained

## Accessibility

Check contrast, font size, dynamic text behaviour, long French strings,
and Danish/French special characters.
